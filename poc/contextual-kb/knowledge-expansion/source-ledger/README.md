# Reviewed source admission inventory

This inventory accounts for every direct heading section of the three guides in `import-manifest.json`: 18 sections and 42 explicit decisions. It maps source content to authored facts, existing equivalent support, exclusions with reasons, and pending candidate admission. It is a human-authored semantic audit checked mechanically, not proof that a parser can discover every true Formly fact.

`ledger.json` is the machine-readable record; `CHECKLIST.md` is generated by `admission/ledger.py report`. Every source and section is hash-pinned, with exact line/character boundaries and decision quotations. Source prose is unchanged. Source hashes establish provenance, not the correctness of interpretation. Independent review must assess the mapping and exclusions.

Current installed scope: all70canonical facts are installed as foundation5, including the six reviewed extension/preset records. Their presence in a candidate directory is not proof they are seeded or installed. Update statuses only after the parent's explicit promotion/qualification decision, and rerun validation/report generation. Do not repin source hashes to hide drift.

## Repeatable commands

From repository root:

```sh
python3 -B poc/contextual-kb/knowledge-expansion/admission/ledger.py check --ledger poc/contextual-kb/knowledge-expansion/source-ledger/ledger.json --authored-dir poc/contextual-kb/authored
python3 -B poc/contextual-kb/knowledge-expansion/admission/ledger.py report --ledger poc/contextual-kb/knowledge-expansion/source-ledger/ledger.json --authored-dir poc/contextual-kb/authored
```

After promotion, omit any now-duplicated candidate authored directory and validate canonical inputs. Add `--require-complete` to reject unresolved sections. Optional read-only DB checking proves referenced IDs are seeded; compiler/rebuild equality and runtime qualification remain separate gates.

## Explicit scope boundaries

This closes the imported-guide inventory only. Supplemental custom-type and initial-value records remain preserved and tested, but this ledger does not pretend their source documents or every retained upstream reference have been exhaustively audited. Source sentences that recommend inspecting applications, historical Angular21 fixtures, inferred fresh-field factory practice, arbitrary preset recursion/null merge behavior, and recommended runtime tests are explicitly excluded from this batch rather than converted into universal library claims.

Broader retained reference backlog: validation/messages, arrays/repeat operations, Material control specifics, and JSON Schema. Each is pending its own source/evidence inventory and isolated comparison. Retired application inspection, supplier demos, indexing experiments and evaluation artifacts are not library-admission inputs. Historical B06/B13 failures remain historical failures.
