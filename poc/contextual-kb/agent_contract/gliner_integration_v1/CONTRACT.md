# Integration contract v1

Use frozen qualification_v3.build_plan and validator. Input is original request plus its unchanged foundation object. Output has the unchanged question_plan, unchanged full-text search_requests, hint_policy advisory_only, optional role_hints and hint_warnings. No generated Formly advice or application investigation.

Three arms: foundation only; foundation plus retained role_boundary_adaptation epoch-6 adapter1701; same plus1702. Both adapters: local gliner2.5-base-v1, pilot/labels.json described labels, threshold0.5, flat decoding, CPUfloat32/fourthreads, inference-only. No verifier, training, selection between seeds, changed labels or threshold tuning.

Run extraction separately on each derived question, never on original application prose or the ledger. Preserve the raw native result and time. Map exact native character start/end/text and role to question_index. Do not repair spans or roles. Malformed native envelope or extraction exception yields no hints for that question plus an explicit diagnostic. Valid hints go through frozen optional_hints; invalid and overlapping hints are rejected there. Predictions remain advisory and usable_as_filter=false. Confidence retained only in raw evidence, never used for new selection. Full question and ledger remain authoritative; hints never become filters, replacements or additional searches. No semantic correctness is inferred from structural acceptance.

Preserve each input and raw result before scoring. Runtime/transport failures stay in denominators. No output retry, resampling or repair; infrastructure recovery before any prediction may be recorded separately. No DB/retrieval access. Existing files immutable, sealed evaluation byte-hash-only, new artifacts exclusively here.
