# Bounded no-training entailment and plan usability protocol

One model: MoritzLaurer/deberta-v3-base-zeroshot-v2.0, revision in model-revision.json. Existing POC environment: Transformers5.20.2, torch2.14.1. No dependency upgrades, finetuning, optimizer, prompt search, threshold selection or best-seed selection. All model/tokenizer files and harness inputs frozen before inference. Direct AutoModelForSequenceClassification sentence-pair scoring uses the model's declared entailment class; no cross-role softmax. Seven fixed textual hypotheses in entailment.py represent six roles plus no-entity. Full question with exact occurrence marked is premise. Reject overlength input instead of silently truncating. Model runs CPU float32/eval/inference_mode, four threads, batch7 hypotheses per occurrence. Fixed policy: top absolute entailment probability >=0.8 and margin over runner-up >=0.2. This is a predeclared diagnostic policy, not calibrated confidence.

Operational inputs are only GLiNER-emitted spans. Same-span competing roles are scored once. Hypothetical relabeling keeps offsets, retains original on abstention/no-entity, and permits one role per accepted span. It never edits raw output or question text. All applied-hypothetical changes, including damage, are counted. No-entity support is diagnostic only; no deletion. Separate supplied-span oracle scores cannot create operational candidates. No span correction or missing-span recovery is attempted. Candidate inference cannot access gold.

Development panels:24 new author-written questions in12 contrast pairs, using the reviewed shadow annotation rule; existing shadow30; and separate adjudicated legacy30. The two old panels reuse frozen raw extraction caches, explicitly not new extraction runs. Both epoch-6 frozen baselines run on fresh24 and all60 question strings from unchanged v2 beta1 (all30 original requests, including the empty-plan request). Legacy original evidence is not rescored under altered labels. New24 not independent-authored; independent review precedes predictions. Prior source overlap is checked and reported, not represented as unseen production traffic.

Scoring: role/support scores and raw outputs saved. Report exact typed-span precision/recall counts, whole-case correctness, correct repairs, wrong changes, lost correct mentions, abstentions, oracle role accuracy, unique inference calls and timing. Cached NLI scores across seeds/panels are explicitly labelled; elapsed run totals are not per-model latency. No production SLA claim. Continue the NLI branch only if each seed has at least one actual operational correction across the labelled development panels, zero wrong changes and zero lost correct mentions on all panels. This is a small-sample experiment gate, not production qualification. Zero opportunities is not success. No post-result retries or tuning.

Question-plan usability: reuse the complete v2 beta1 panel; do not regenerate v2 or edit its outputs. The diagnostic plan consists of verbatim library questions and unchanged constraints, with extraction annotations available separately as optional hints. No hard role filters, canonical entity linking, DB/search calls, answer generation or serving integration. Independent reviewer assesses all30 original requests and the60 focused questions paired with each seed's raw annotations. Report separately (a) preservation and focus of the text-only library-question plan, (b) whether structured role hints are safe as-is, and (c) whether an annotation defect blocks text-based search formulation or merely makes the hint unreliable. Empty plans evaluated against original request, not auto-passed. A usable text query is not proven executable retrieval, corpus answerability or final-answer accuracy. NLI alternative annotations may be inspected for harmful suggestions; no serving adoption occurs.

Review: preparation, tests, code, data and policy before inference; independent result/usability assessment afterward. Up to three fresh review instances total, no unbounded revisions. Preserve baseline weights, A, v2, prior artifacts and locked data/DB with inherited manifests plus new source bindings and frozen input hashes; sealed files may only be preservation-hashed, never parsed or supplied to models/reviewers. New artifacts only in this folder plus BEST-QUESTION-CONFIGURATIONS.md at POC root.

Research: https://aclanthology.org/2022.tacl-1.35/ supports entity typing as NLI; https://huggingface.co/MoritzLaurer/deberta-v3-base-zeroshot-v2.0 documents binary entailment and direct Transformers loading. https://huggingface.co/docs/transformers/v5.20.2/en/main_classes/pipelines documents NLI label scoring. These sources establish APIs/method precedent, not Formly accuracy. Installed direct API and label mapping are checked locally before inference.
