## Choices and limits
This is testing, not another architecture change. No training, retrieval/answer experiments, semantic detector, repair pipeline or production integration. Generation uses native agents/instruction packets rather than pinned deployed API parameters; provider revision,temperature,seed uncontrolled. Role separation is context isolation, not vendor independence. Synthetic authored cases and correlated repeats cannot establish a production accuracy rate or universal determinism. No contemporary comparator, latency budget test, retrieval utility or final-answer test. Preserved hashes establish contents, not unseen generation provenance.
