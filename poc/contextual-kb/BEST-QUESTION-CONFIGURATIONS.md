# Best tested question-layer configurations

Recorded 2026-10-23 before the entailment experiment. This is an evidence inventory, not promotion or a new qualification gate. Different panels and metrics cannot be combined into one accuracy ranking.

1. **Library-question derivation: agent contract v2.** Source: `agent_contract/refinement_v2/CONTRACT.md` and `prompt.py`. The common semantic/structure rubric passed 120/120 responses across 30 distinct requests and four runs; targeted representation checks passed 24/24. Grading was agent-based and repeats were correlated. Exact JSON was stable on only 1/30 forward-repeat cases; provider revision/sampling and production latency were uncontrolled. Best supported agent contract for further POC work, not deterministic generation or answer qualification. Evidence: `agent_contract/refinement_v2/RESULTS.md`.

2. **Strongest retained contextual extractors: both role/boundary-adaptation epoch-6 adapters, seeds 1701 and 1702.** Paths: `gliner_feasibility/narrow_contract/role_boundary_adaptation/test-output/after-{1701,1702}/epoch-6/adapter`. Base: local GLiNER2.5 base-v1, six described entity roles from `narrow_contract/pilot/labels.json`, threshold 0.5, native `overlap_policy='flat'`, CPU float32, four threads. Continued LoRA training used 194 questions (48 contrast plus146 replay), six epochs,150updates, AdamW1e-4 and accumulation8. Fresh40 exact envelopes:35/40 and36/40; accepted typed-span F1:97.14% and98.10%. Neither passed strict replacement/qualification gates. Same-span competing roles and some API/role/boundary errors remain. Keep both; do not select a seed based on a favorable panel. Evidence: `gliner_feasibility/narrow_contract/role_boundary_adaptation/RESULTS.md`.

3. **Best supported decoding setting: native flat decoding.** Earlier trained-model fresh48 run produced38/48 and39/48 exact envelopes, zero invalid outputs, typed-span F1 92.6%/93.4%. These were earlier epoch-8 checkpoints, not the epoch-6 adapters above. Flat decoding is per-label and does not guarantee mutual exclusion across roles. It is a useful setting, not a universal conflict fix. Evidence: `gliner_feasibility/narrow_contract/fresh_flat/RESULTS.md` and `native_decoding/RESULTS.md`.

4. **Fast reference planner: A (spaCy dependency projection).** spaCy3.8.16 / en_core_web_sm3.8.0 plus custom projection rules. Median3.94ms, p955.88ms;17/30 complete plans and one case with critical error in the frozen A/B comparison. B achieved18/30 with two critical-error cases and median1.480s. Neither met the27/30 floor. A remains a speed/reference baseline, not an approved question planner. Evidence: `QUESTION-PLAN-RESULTS.md`.

5. **Current candidate combination for assessment: unchanged v2 plus each unchanged epoch-6 extractor, without learned verifier.** This composition has not yet been qualified as a complete question layer. Latest shadow development test:28/30 and29/30 correct mentions, one/zero extras. The frozen verifier proposed four wrong roles on correct mentions per seed and no successful wrong-role repairs. Do not attach it to the candidate. Evidence: `gliner_feasibility/narrow_contract/verifier_shadow/RESULTS.md`.

No other later verifier, attribute, distillation or conflict-resolution variant is recorded as a promoted replacement. Their reports remain provenance; failure to improve a stronger checkpoint does not erase that checkpoint's gains. All configurations remain experimental, and none establishes retrieval or final-answer accuracy. A, v2, both baselines and the data/DB remain frozen; evaluation stays sealed.
