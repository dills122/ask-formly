Intent: expose the accepted POC foundation through one local raw-question MCP tool. No change to foundation, GLiNER checkpoints, retrieval, stored data/index or prior candidates. User explicitly authorized serving and real-agent qualification after the earlier integration closeout.

Plan: task_plan.md and PROTOCOL.md define input, output, error behavior, native test and usability gates. Code and cases frozen before qualification in test-output/qualification-freeze.json. Three fresh development repetitions through real Codex callers; no tuning during them. Qualification may still be running when review starts; final verdict must wait for results.

Flow: server.create_server uses pinned official Python SDK FastMCP stdio and typed structured output. LookupService serializes requests through a single executor thread to preserve SQLite and worker ownership, validates the raw string then frozen build_plan, and latches observed integrity failure. CodexPlanner invokes installed Codex exec with exact frozen contract as model instructions, strict JSON schema, explicit gpt-6-astra/medium, no user config, no shell/web/multi-agent, ephemeral context. No plan retries or semantic repair. Backend persists read-only DB/PilotIndex and AdvisoryLookup with frozen ProcessExtractor; verifies model hashes per call, propagates known integrity changes, degrades ordinary verification unavailability. Complete returned facts are unchanged; stored citations are separate metadata. Calling agent assesses support; server returns candidate_only.

Environment: new mcp_v1/.venv and local UV cache. Existing retrieval env lacks MCP SDK, so install SDK and same fastembed version in new env. Retrieval dependency versions match original except certificate bundle; all versions locked. GLiNER runs in existing frozen environment. Authenticated Codex uses existing login; no key copied or read. Planner processes require provider network access. Initial sandbox/cache failures retained as diagnostic evidence; authorized install/runtime executed outside restricted sandbox. No global MCP registration or deployment.
