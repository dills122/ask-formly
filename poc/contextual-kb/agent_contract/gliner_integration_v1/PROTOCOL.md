# Fixed integration criteria

Freeze contract, criteria, source requests before generation. Then freeze adapter/tests/complete inputs and semantic annotations before extractor inference. No tuning during execution.

Safety panel: all162 saved qualification_v3 outputs (48fresh+6diagnostic, each3runs) plus12 newly authored development requests with one first foundation output each. All three arms consume identical objects. New foundation outputs manually assessed for requested aspects, scope, constraints and ledger; failures retained and separately reported. No new question-layer qualification claim from12single runs.

Extraction panel: the first derived question from run1 of P02,P04,P06,P08,P10,P12,P14,P16,P18,P20,P22,P24,P26,P28,P30,P32,P34,P36,P38,P40,P42,P44,P46,P48 (empty questions counted as empty controls, no synthetic question), plus every derived question from the12fresh requests. Annotate all exact spans and six roles before model predictions under frozen pilot label definitions. Quoted narrative excluded; opaque code expressions whole; complete API paths; hypothetical APIs included. Enumerate every occurrence. Confidently ambiguous spans get an explicit alternatives list before inference; score common-required separately from alternatives, never choose gold after output. Review annotations before freezing. Other saved questions receive safety/coverage audits only, not claimed precision/recall.

Report both raw native and accepted hints: exact typed-span TP/FP/FN, precision/recall/F1 (undefined denominators null), exact question sets, untyped boundary scores, cross-role same-span conflicts, filtering losses and residual errors by role. Repeated qualification outputs are correlated and not independent precision samples. Baseline annotation metrics reported as absence, not falsely 100percent accurate; baseline usefulness is full-text query availability.

Mandatory safety: all174scheduled records delivered/accounted; zero differences in core question_plan/search_requests versus foundation alone, zero input mutations; every accepted hint exact anchored and usable_as_filter=false. Fault injection covers exceptions, malformed output, wrong offsets, unknown roles, overlap, no mentions, repeated text and empty/out-of-scope input. No existing artifact hash drift. Any core alteration blocks integration.

Advisory value gate PER MODEL: no runtime extraction failures; accepted typed precision>=0.95 and recall>=0.80 on the combined pre-annotated panel; correct accepted spans in>=50percent of gold-nonempty questions; no accepted hints on gold-empty controls. Role-specific scores and new-panel scores reported even if aggregate passes. A passing value gate establishes only usefulness as typed-index metadata, NOT retrieval improvement. Neither seed may hide the other's failure; recommend required integration only if safety AND both value gates pass, otherwise retain foundation-alone path and classify extractor optional experimental metadata or reject it based on errors. Even a pass does not make hints authoritative.

Timing: sequential model runs, no concurrent model workloads; model/import cold setup separately, raw per-question extraction seconds and per-request sum, p50/p95/max, plus projection timings for all arms. Measure actual work; no cached prediction substitution or end-to-end/agent latency claim. One pass is diagnostic, no latency SLA. No sealed evaluation, retrieval, answer scoring, training or automatic promotion. Independent preflight and completed-results review, maximum3instances.
